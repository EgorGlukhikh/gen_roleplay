# Тайная книга

Генератор эпизодов для форумной игры во вселенной Гарри Поттера времён Мародеров.
1304 карточки, взрослые и школьные истории, 15 типов отношений и готовое оформление в BBCode `[html]`. В версии 4 добавлены 768 карточек: по шесть разных событий для каждого из 128 доступных сочетаний отношений, сферы и возраста. Это 72 новых событийных основы с фиксированными адаптациями под отношения, а не 768 совершенно непохожих событий. Внутри каждого сочетания новые основы различаются. У 180 историй предыдущей версии сохраняются два дополнительных варианта.

Сайт: https://egorglukhikh.github.io/gen_roleplay/

## Обновление

1. Изменить `src/library.json` (истории и связанные продолжения), `src/ui.js`, `src/engine.cjs` или `src/page.html`.
2. Выполнить в Node.js 22 или новее:

   ```sh
   node --test src/coherence.test.cjs src/variation.test.cjs src/catalogue.test.cjs src/density.test.cjs
   node scripts/build.cjs
   ```

3. Закоммитить исходники и обновлённую папку `docs` в `main`.

Зависимости устанавливать не нужно. Страница собирается без сжатой форумной упаковки, внешних библиотек, API или секретных ключей.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/docs` → Save.
В форумное сообщение вставляется содержимое `forum-embed.txt`. Если iframe удерживает старую версию в кэше, замените параметр `?v=` в адресе на идентификатор нового выпуска.

## Логика

Дополнения разрешены только для явно связанных историй через поле `continuation`; общая сфера не даёт права смешивать сюжеты. У самостоятельных историй дополнительного абзаца нет. Варианты в `variants` могут заменять заголовок и текст. Исходные идентификаторы сценариев стабильны.

Поле `relation` содержит только проверенные категории; универсального `*` нет. Причины вражды и предмет соперничества находятся в тексте сцены. `review` фиксирует редакторское решение. Любовники, супруги, бывшие партнёры и родитель со взрослым ребёнком доступны во взрослой главе. В последней категории первое имя всегда обозначает родителя; остальные категории могут менять порядок двух главных ролей.

Украшения по отношениям находятся в `docs/assets/relations`. Это изображения, созданные встроенным imagegen; прозрачность сохранена. В копируемой карточке используются абсолютные адреса Pages. При смене адреса хостинга обновите их в `src/engine.cjs`.

`scripts/*expansion*.cjs` и `scripts/review-catalogue.cjs` сохраняют исходные материалы и одноразовую миграцию версии 3. Повторно выполнять миграцию не нужно: рабочий каталог — `src/library.json`.

История повторов хранится в браузере для каждой пары имён. Сначала выбираются основы, отсутствующие среди последних 30 результатов, затем чередуются механизмы; редкий механизм больше не заставляет повторять историю при наличии свежих. Между устройствами история не синхронизируется. Ники не отправляются на сервер генератора.

`scripts/density-data.cjs` и `scripts/expand-density.cjs` сохраняют основы и фиксированные контексты версии 4. Они компилируются в готовые сцены; случайного склеивания абзацев при генерации нет. Повторно запускать миграцию не нужно.

При ограничениях буфера обмена карточку можно скачать текстовым файлом. В исходники и публичную библиотеку не следует добавлять приватные данные игроков.
